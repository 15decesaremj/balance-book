# Support

Balance Book is community-supported software. It does not provide individualized financial advice, bank services, guaranteed data recovery, or an emergency support channel.

## Before requesting help

1. Confirm that the installed version is covered by [SUPPORTED_VERSIONS.md](docs/SUPPORTED_VERSIONS.md).
2. Create an encrypted portable backup before troubleshooting anything that could change stored data.
3. Review [INSTALLATION.md](docs/INSTALLATION.md) and [BACKUP_RESTORE.md](docs/BACKUP_RESTORE.md).
4. Search existing issues for a report that uses synthetic data and matches the behavior.

## Public support requests

When the repository is public, use a GitHub issue for non-sensitive bugs and feature requests. Include the Balance Book version, Windows version and architecture, expected behavior, actual behavior, and minimal steps using invented values.

Never attach a real database, workbook, backup, export, log, account number, credential, screenshot, user directory, or financial record. Maintainers may close or remove content that risks exposing private information.

Security issues must be reported privately using the process in [SECURITY.md](SECURITY.md).

## Data and password recovery

Maintainers cannot recover a forgotten sign-in password or encrypted-backup password. A password-encrypted backup cannot be restored without its backup password. Keep verified backups and passwords in separate, secure locations.
