# Release notes

Balance Book adds a trusted Microsoft Store edition with Store-managed updates and an isolated,
copy-first migration from an existing direct-download profile. Store and direct editions retain
their own application data, while encrypted portable backup remains available for recovery or
moving to another computer.

The Store edition disables the direct GitHub updater and clearly identifies Microsoft Store as its
update provider. First-time setup now records express consent before financial information is
entered and links to the public privacy policy.
